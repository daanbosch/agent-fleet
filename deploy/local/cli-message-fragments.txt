# Upstream message fragments Agent Fleet matches on, checked by cli-fragment-check.sh on
# every CLI version bump (cli-pin-bump.sh). One row per fragment, TAB-separated:
#
#   <kind>  <fragment>  <where the code matches on it, and why>
#
# - The fragment is a literal string (grep -F), written the way the upstream package
#   spells it, ASCII only. It may hold spaces, but no TAB and no backtick (it is quoted in
#   Markdown). Where the code compares case-insensitively, register the upstream's casing.
# - A fragment belongs here only if a literal run of it sits in the package as one piece.
#   One built by string concatenation or kept in an escaped form is invisible to a plain
#   byte search; the checker reports such a row as "unverifiable" instead of passing it
#   (see the header of cli-fragment-check.sh).
# - A kind needs an unpack recipe in cli-fragment-check.sh; without one its rows are
#   reported as "not checked". Add a row here when new code starts matching on upstream
#   text (e.g. the expired-OAuth prompt of #2180).
#
