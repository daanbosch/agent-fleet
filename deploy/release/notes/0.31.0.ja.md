テナントのメンバー同士が新しい受信箱でメッセージや依頼を送り合えるようになり、利用枠の状況を利用枠ボードで
共有でき（任意）、待っているものが一目でわかるホームが開きます。エージェントメモリは設定に閲覧画面が加わって
検索・編集・復元・履歴からの削除ができ、muse とメモリのバンドルからも取り込めます。ワークスペースの持ち主は、
待ち受けているポートを登録せずにプレビューで開けます。

### New

- **受信箱。** 通知ベルの横の受信箱ボタンから、テナントのほかのメンバーへメッセージや依頼を送れます。依頼は受け手の
  1 人が引き受け、そこからセッションを始め、セッションや PR のリンクを付け、完了にできます。誰から受け取るかは
  「受信設定」タブで選びます。
  ([#1961](https://github.com/k-k1/agent-fleet/issues/1961))
- **利用枠ボード。** 設定 › 利用枠ボード で、自分のエージェントの利用枠の状況をテナント全体または選んだメンバーに、
  状態だけ・目安の帯・正確な値のいずれかで公開できます。オンにするまでは何も公開されず、テナント管理者は
  ボードごとオフにできます。
  ([#1962](https://github.com/k-k1/agent-fleet/issues/1962))
- **ホーム。** 空のレイアウトに「あなたの返事を待っています」「続きから」「新しく始める」を表示し、初回の
  チェックリストもここへ移りました。WS バーのホームボタンか `g h` で開きます。チェックリストを閉じた状態は
  どの端末でも保たれます。
  ([#2028](https://github.com/k-k1/agent-fleet/issues/2028),
  [#2027](https://github.com/k-k1/agent-fleet/issues/2027))
- **テナント › メンバーの既定** で、新しいメンバーに初日に接続してもらうエージェントを指定できます。
  ([#2026](https://github.com/k-k1/agent-fleet/issues/2026))
- **エージェントメモリの閲覧。** 設定 › エージェントメモリ › 「メモリを閲覧」で、すべての範囲のメモリを一覧し、
  名前と本文を検索し、作成・編集・忘れさせる・復元ができます。メモリの過去の版を履歴から削除することもできます。
  ([#1985](https://github.com/k-k1/agent-fleet/issues/1985),
  [#1999](https://github.com/k-k1/agent-fleet/issues/1999),
  [#2003](https://github.com/k-k1/agent-fleet/issues/2003),
  [#2007](https://github.com/k-k1/agent-fleet/issues/2007),
  [#1997](https://github.com/k-k1/agent-fleet/issues/1997),
  [#1982](https://github.com/k-k1/agent-fleet/issues/1982))
- **Agent Fleet のメモリへの取り込み口が増えました。** 「muse から取り込む」で muse のプロジェクトと個人のメモリを
  取り込め、メモリのバンドルに入った Agent Fleet のメモリもこのワークスペースへ取り込めます。作業コピーが
  なくなったプロジェクトに残ったメモリは別のプロジェクトへ移動・統合でき、git のリモートが一致すれば Console が
  移動先を提案します。
  ([#1991](https://github.com/k-k1/agent-fleet/issues/1991),
  [#2005](https://github.com/k-k1/agent-fleet/issues/2005),
  [#1983](https://github.com/k-k1/agent-fleet/issues/1983),
  [#1984](https://github.com/k-k1/agent-fleet/issues/1984),
  [#2110](https://github.com/k-k1/agent-fleet/issues/2110))
- **どのポートでもプレビューで開けます。** 持ち主は、ワークスペースが待ち受けているポートを、先にポート一覧へ
  追加しなくてもワークスペースのプレビュー用サブドメインで開けます。ほかの人が見られる範囲は引き続き一覧で決まります。
  ([#2138](https://github.com/k-k1/agent-fleet/issues/2138))
- **Markdown のファイル・フォルダのリンクを右クリック**（または長押し）すると、ペインで開く、ファイルで表示、
  パスのコピー、ダウンロードなどのメニューが出ます。
  ([#2059](https://github.com/k-k1/agent-fleet/issues/2059))
- **Bitbucket の CLI `bkt` をワークスペースのイメージに同梱しました。** GitHub の `gh` と同じく、Bitbucket の
  接続を使ってサインインします。
  ([#2079](https://github.com/k-k1/agent-fleet/issues/2079))
- **home ごとの資格情報ストアの鍵（運用者向け・任意）。** KMS の鍵管理を使っている場合、ECS のパラメータ
  `WorkspaceDekRandom=on` で各メンバーの home に専用のランダムな鍵を持たせられます。`af-cp rewrap-keys` は、
  KMS へ切り替える前に保存した値を封印し直します。
  ([#1646](https://github.com/k-k1/agent-fleet/issues/1646),

### Upgrade notes

- **ECS**: 新しいパラメータを反映するため `update.sh` を実行してください。`Persistence=retain` で EFS の
  バックアップがないと警告されたら、ECS の手順書のステップ 1a に従ってください。それまで Console は管理者に
  警告を出します。`WorkspaceDekRandom` は設定しない限り `off` のままです。
- **エージェントメモリ**: オンの間、アップグレード後に起動した muse のセッションは muse 自身のメモリを
  使いません。ファイルは残っているので、設定 › エージェントメモリ の「muse から取り込む」で、muse が覚えたことを
  Agent Fleet のメモリへ取り込んでください。
