opencode now runs on opencode 2 (2.0.29) for everyone, after a release of groundwork: Terminal
(CLI) sessions share one opencode server, questions arrive as forms, and conversations from before the
upgrade carry over. Going back to opencode 1 is a rebuild with the old pin.

### Improved

- **opencode is now opencode 2.** The image pins opencode 2.0.29 instead of 1.19.0. Managed and
  Terminal (CLI) sessions use it, and the member guide describes it as the way opencode works. Note
  that opencode 2 reads only `AGENTS.md` (no `CLAUDE.md` fallback) and has no ToDo list.
  ([#2105](https://github.com/k-k1/agent-fleet/issues/2105),
  [#2134](https://github.com/k-k1/agent-fleet/issues/2134))
- **A workspace that tried the opencode 2 opt-in** (`opencode-major 2`) now simply uses the pinned
  opencode 2. `install-opencode2` and `opencode-major` explain this and change nothing.
  ([#2133](https://github.com/k-k1/agent-fleet/issues/2133))

### Upgrade notes

- **Your opencode conversations carry over.** The first opencode 2 start on a workspace converts
  opencode's database (`~/.local/share/opencode/opencode.db`) in place and imports the existing
  sessions once, with the same session ids, so Managed and Terminal (CLI) sessions resume as before.
- **The opt-in's own data is not merged.** If you ran `opencode-major 2` before, the sessions that
  exist only in its private database (`~/.local/share/agent-fleet/opencode2-data`) are not visible
  to the pinned opencode 2. Nothing is deleted; remove that directory and
  `~/.local/share/agent-fleet/opencode2` when you no longer need them.
- **Going back to opencode 1.** Rebuild the image with `--build-arg OPENCODE_VERSION=1.19.0` and
  restart the workspaces. opencode 1 sees every conversation from before the upgrade, but not the
  ones created, or the turns added, under opencode 2. To undo the upgrade exactly, copy
  `~/.local/share/opencode/opencode.db*` before the first start on this release and put the copies
  back after the way back.

Agent CLI pins: OpenCode 2.0.29 (was 1.19.0).
