opencode が全員で opencode 2（2.0.29）になります。前のリリースまでに土台が揃っています。ターミナル（CLI）セッションは
1 つの opencode サーバーを共有し、質問はフォームで届き、アップグレード前の会話もそのまま引き継がれます。
opencode 1 に戻すには、古いピンでイメージを再ビルドします。

### 改善

- **opencode が opencode 2 になりました。** イメージのピンが opencode 1.19.0 から 2.0.29 に変わります。
  マネージド・ターミナル（CLI）のどちらのセッションも opencode 2 を使い、メンバー向けガイドも opencode 2 の
  動きを前提に書き換わりました。opencode 2 は `AGENTS.md` だけを読み（`CLAUDE.md` には切り替えません）、
  ToDo リストはありません。
  ([#2105](https://github.com/k-k1/agent-fleet/issues/2105),
  [#2134](https://github.com/k-k1/agent-fleet/issues/2134))
- **opencode 2 のオプトイン（`opencode-major 2`）を試していたワークスペース**は、これからはピン止めされた
  opencode 2 をそのまま使います。`install-opencode2` と `opencode-major` はその旨を表示するだけで、何も変更しません。
  ([#2133](https://github.com/k-k1/agent-fleet/issues/2133))

### アップグレードの注意

- **opencode の会話は引き継がれます。** このリリースでの最初の opencode 2 起動時に、opencode のデータベース
  （`~/.local/share/opencode/opencode.db`）をその場で変換し、既存のセッションを同じセッション ID のまま 1 回だけ
  取り込みます。マネージド・ターミナル（CLI）のセッションはこれまでどおり再開できます。
- **オプトインの専用データは統合されません。** 以前に `opencode-major 2` を使っていた場合、専用データベース
  （`~/.local/share/agent-fleet/opencode2-data`）にしかないセッションは、ピン止めされた opencode 2 からは見えません。
  何も削除されません。不要になったら、このディレクトリと `~/.local/share/agent-fleet/opencode2` を削除してください。
- **opencode 1 に戻すとき。** `--build-arg OPENCODE_VERSION=1.19.0` を付けてイメージを再ビルドし、ワークスペースを
  再起動します。opencode 1 からは、アップグレード前の会話はすべて見えますが、opencode 2 で作った会話や、
  opencode 2 で足したターンは見えません。アップグレードを正確に取り消したいときは、このリリースでの最初の起動の前に
  `~/.local/share/opencode/opencode.db*` をコピーしておき、戻したあとに書き戻してください。

エージェント CLI のピン: OpenCode 2.0.29（1.19.0 から）。
