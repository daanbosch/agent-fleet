Members of a tenant can send each other messages and requests through a new inbox, opt in to
sharing their usage limits on a limit board, and land on a Home view that shows what is waiting for
them. Agent memory gets a browser in Settings with search, edit, restore and purge, and imports from
muse and memory bundles. The owner of a workspace can open any port it listens on in the preview
without registering it first.

### New

- **Inbox.** The inbox button beside the notification bell sends messages and requests to other
  members of the tenant. A request is taken by one recipient, who can start a session from it, attach
  sessions and a PR link, and mark it done. The **Receiving** tab chooses who may send to you.
  ([#1961](https://github.com/k-k1/agent-fleet/issues/1961))
- **Limit board.** Settings › Limit board lets a member publish their agents' usage-limit state to the
  tenant or to chosen members, as state only, a band or the exact value. Nothing is published until
  you turn it on, and a tenant admin can switch the board off.
  ([#1962](https://github.com/k-k1/agent-fleet/issues/1962))
- **Home.** An empty layout now shows **Waiting for you**, **Continue** and **Start something**,
  and the first-run checklist moves there. Open it from the WS bar's Home button or `g h`. Dismissing
  the checklist now holds on every device.
  ([#2028](https://github.com/k-k1/agent-fleet/issues/2028),
  [#2027](https://github.com/k-k1/agent-fleet/issues/2027))
- **Tenant › Member defaults** names the agent new members are asked to connect on their first day.
  ([#2026](https://github.com/k-k1/agent-fleet/issues/2026))
- **Browse agent memory.** Settings › Agent memory › **Browse memories** lists the memories of every
  scope, searches names and bodies, creates and edits them, forgets and restores them, and can purge
  a memory's past revisions from history.
  ([#1985](https://github.com/k-k1/agent-fleet/issues/1985),
  [#1999](https://github.com/k-k1/agent-fleet/issues/1999),
  [#2003](https://github.com/k-k1/agent-fleet/issues/2003),
  [#2007](https://github.com/k-k1/agent-fleet/issues/2007),
  [#1997](https://github.com/k-k1/agent-fleet/issues/1997),
  [#1982](https://github.com/k-k1/agent-fleet/issues/1982))
- **More ways into Agent Fleet memory.** **Import from muse** brings in muse's project and personal
  memories, and a memory bundle's Agent Fleet memory can be imported into this workspace. Memories
  left behind by a project whose working copy is gone can be moved or merged into another project,
  and the Console suggests the target when the git remote matches.
  ([#1991](https://github.com/k-k1/agent-fleet/issues/1991),
  [#2005](https://github.com/k-k1/agent-fleet/issues/2005),
  [#1983](https://github.com/k-k1/agent-fleet/issues/1983),
  [#1984](https://github.com/k-k1/agent-fleet/issues/1984),
  [#2110](https://github.com/k-k1/agent-fleet/issues/2110))
- **Open any port in the preview.** The owner can open any port the workspace listens on, on the
  workspace's preview subdomain, without adding it to the port list first; the list still decides
  what other people can reach.
  ([#2138](https://github.com/k-k1/agent-fleet/issues/2138))
- **Right-click a file or folder link in Markdown** (or long-press) for a menu to open it in a pane,
  show it in Files, copy its path, download it and more.
  ([#2059](https://github.com/k-k1/agent-fleet/issues/2059))
- **The Bitbucket CLI `bkt` is in the workspace image** and signs in through your Bitbucket
  connection, as `gh` does for GitHub.
  ([#2079](https://github.com/k-k1/agent-fleet/issues/2079))
- **Per-home credential-store keys (operators, opt-in).** With the KMS key custodian, the ECS
  parameter `WorkspaceDekRandom=on` gives each member's home its own random key, and `af-cp
  rewrap-keys` re-seals values stored before the switch to KMS.
  ([#1646](https://github.com/k-k1/agent-fleet/issues/1646),
  [#1979](https://github.com/k-k1/agent-fleet/issues/1979),
  [#1645](https://github.com/k-k1/agent-fleet/issues/1645),
  [#1956](https://github.com/k-k1/agent-fleet/issues/1956))

### Improved

- **Turning Agent memory on or off now carries claude's memory across by itself**: switching on
  imports claude's own memory, and switching off writes Agent Fleet memory back. While the switch is
  on, muse's own memory is off too.
  ([#1972](https://github.com/k-k1/agent-fleet/issues/1972),
  [#1990](https://github.com/k-k1/agent-fleet/issues/1990))
- **`memory_search` ranks hits by how well they match**, and a multi-word query that matches nothing
  falls back to any of the words and says so. Memory reads stay fast with hundreds of memories.
  ([#1981](https://github.com/k-k1/agent-fleet/issues/1981),
  [#1995](https://github.com/k-k1/agent-fleet/issues/1995))
- **A memory write in the changed-files strip opens** instead of showing as outside the working copy.
  ([#2148](https://github.com/k-k1/agent-fleet/issues/2148))
- **Handing a session to a member**: received handoffs appear in the inbox, members are named by
  e-mail, and when unpushed commits block the handoff the dialog offers **Push, then send**.
  ([#2075](https://github.com/k-k1/agent-fleet/issues/2075),
  [#2072](https://github.com/k-k1/agent-fleet/issues/2072))
- **Sharing and handoff dialogs open quickly for members with many sessions.**
  ([#2074](https://github.com/k-k1/agent-fleet/issues/2074),
  [#2098](https://github.com/k-k1/agent-fleet/issues/2098))
- **Stopped claude conversations are kept and backed up.** claude no longer deletes its old
  conversation logs, and a stopped session's log is backed up and restored on resume. If a log is gone
  anyway, the session is not silently restarted empty; the Console asks first.
  ([#2062](https://github.com/k-k1/agent-fleet/issues/2062),
  [#2073](https://github.com/k-k1/agent-fleet/issues/2073))
- **`/model` in claude no longer stops at the "Switch model?" dialog.**
  ([#1920](https://github.com/k-k1/agent-fleet/issues/1920))
- **The preview and browser pane say why a port failed** — nothing listening, not HTTP, or HTTPS —
  instead of always "nothing is listening".
  ([#2139](https://github.com/k-k1/agent-fleet/issues/2139),
  [#2151](https://github.com/k-k1/agent-fleet/issues/2151))
- **An expired Claude login is one click away**: a send it refuses offers **Re-authenticate**, and the
  start dialog says so when Claude is chosen.
  ([#2125](https://github.com/k-k1/agent-fleet/issues/2125))
- **A role-chaining AWS profile follows its source's sign-in** in the WS bar, and the badge counts the
  source once.
  ([#1109](https://github.com/k-k1/agent-fleet/issues/1109))
- **A frozen Terminal session of codex, cursor, copilot, kiro or opencode** stops keeping its
  workspace awake after an hour without output.
  ([#1830](https://github.com/k-k1/agent-fleet/issues/1830))
- **Antigravity Terminal sessions** track their conversation and working/idle state more reliably.
  ([#2156](https://github.com/k-k1/agent-fleet/issues/2156))
- **A Managed opencode session shows a provider error while it retries**, and fails the turn on an
  error no retry can fix.
  ([#2129](https://github.com/k-k1/agent-fleet/issues/2129))
- **lcpp sessions with many MCP tools** reach them through a small search tool, keeping each request
  short.
  ([#1565](https://github.com/k-k1/agent-fleet/issues/1565))
- **ecs-ec2 slots launched from an older launch template are replaced at the workspace's next Start**,
  without a reservation; the home is kept.
  ([#1934](https://github.com/k-k1/agent-fleet/issues/1934))
- **Admins of a `Persistence=retain` ECS deployment without daily EFS backups see a warning** in the
  Console, and `update.sh` checks for it.
  ([#2063](https://github.com/k-k1/agent-fleet/issues/2063),
  [#2066](https://github.com/k-k1/agent-fleet/issues/2066))

### Upgrade notes

- **ECS**: run `update.sh` to pick up the new parameters. If it warns that `Persistence=retain` has no
  EFS backup, follow step 1a of the ECS runbook; until then the Console shows the warning to admins.
  `WorkspaceDekRandom` stays `off` unless you set it.
- **Agent memory**: while it is on, muse sessions started after the upgrade no longer use muse's own
  memory. Its files are kept; use **Import from muse** in Settings › Agent memory to bring
  what muse has learned into Agent Fleet memory.
